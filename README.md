# 🌀 Sudarshan Chakra 365

AI-Driven Micro-Task Ecosystem for continuous skill validation, earning, and trust building.

---

## 🚀 Overview

Sudarshan Chakra 365 is a circular learning and earning system where:

- 🤖 AI generates daily micro-tasks (365 days)
- 👨‍👩‍👧 Parents sponsor tasks (set price)
- 👦 Children complete tasks (earn rewards)
- 🧑‍⚖️ Reviewers validate and distribute rewards
- 📊 Chakra Dashboard visualizes progress in a 365-day circular format

---

## 🧠 Core Concept

A **365-day circular system (Sudarshan Chakra)**:
- Outer ring → AI Load
- Inner rings → View → Work → Earn
- Center → Trust Score
