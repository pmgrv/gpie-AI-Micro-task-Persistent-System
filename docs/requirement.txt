⚙️ 3. Backend Setup (Server)
Step 1: Go to server
cd server
Step 2: Install dependencies
npm install
Step 3: Configure .env

Create file: server/.env

DB_USER=postgres
DB_HOST=localhost
DB_NAME=sudarshan_db
DB_PASS=yourpassword
DB_PORT=5432
PORT=5000

⚠️ Replace:

yourpassword → your actual PostgreSQL password
Step 4: Start server
npm run dev
